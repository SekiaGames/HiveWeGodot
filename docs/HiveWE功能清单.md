# HiveWE 功能清单

从使用者视角列出 HiveWE 具备的地图编辑能力，标出哪些做完了、哪些只有界面。这份清单用来界定移植范围。

依据：`native/_upstream/src/menus/*.ui`、`main_window/main_ribbon.cpp`、`brush/`、`base/`。

## 定位

War3 世界编辑器的第三方替代品。编辑对象是地图文件（`.w3m` / `.w3x` / 解包后的目录），改动最终写回 `war3map.*` 系列文件。游戏运行交给 War3 本体。

## 1. 地图文件管理

| 功能 | 说明 |
|---|---|
| New Map | 选尺寸、地形集，生成空白图（`Terrain::save_blank`，纯草地 + 边界水位） |
| Open Map (Folder) | 打开解包的地图目录，改一个文件即时生效 |
| Open Map (MPQ) | 直接打开 `.w3m` / `.w3x`。HiveWE 还支持重制版的 CASC，本工程不做 |
| Save / Save As | 原样回存，未识别字段保留 |
| Export Map | 导出成可运行的包 |
| Test Map | 导出后调 War3 启动 |
| Protection | 地图保护 / 解保护 |
| Import Manager | 地图内嵌资源（`war3map.imp`）的增删 |

「打开文件夹」这个设计值得保留：调试时改一个 `.w3e` 就能看到效果，不用反复解包重打包。

## 2. 地形

做得最完整的一块。

| 功能 | 细节 |
|---|---|
| 高度抬升 / 降低 | 圆形 / 方形 / 菱形笔刷，线性衰减，按帧累加 |
| 平台化 | 压到按下瞬间的中心高度，一次到位 |
| 平滑 | 3×3 卷积，缓动系数 0.03，需要持续涂抹 |
| 地面纹理 | 从当前地形集的纹理列表里选，含 blight 版本 |
| 悬崖 | 放置 / 升降、选悬崖类型、生成坡道、相对高度模式 |
| 水面高度 | 与地面高度分开编辑 |
| Cell 操作 | 直接涂水 / 陆 / blight，按格不按顶点 |
| 笔刷尺寸 | 预设按钮 + 滑条，支持到 1000+ 格 |
| 联动开关 | Enforce Water Height Limit、Update Doodad Z、Cliff/Tile/Water Pathing |
| 高度图导入 | 读一张图片的红通道，映射到 -16~+16 覆盖整张图 |
| 撤销 / 重做 | 按高度 / 纹理 / 悬崖 / 水四类分别入栈 |

UI 分四组：Deformation、Texture、Cliff、Cell。

## 3. 路径（Pathing）

HiveWE 区别于「地形查看器」的核心功能。

| 功能 | 细节 |
|---|---|
| Pathing 图编辑 | 每 tile 4×4 子格，walkable / flyable / buildable 三通道独立涂 |
| 三种操作 | 替换 / 添加 / 移除 |
| 自动联动 | 地形、悬崖、水、装饰物放置时自动更新路径（可关） |
| 导入 / 导出 | 路径图当图片导入导出 |
| 全局 tile pathing | 每种地形纹理的默认可走性，改一次影响全图同类地块 |
| 可视化 | 叠加在地形上，红 / 绿 / 蓝染色，实时更新 |

## 4. 装饰物（Doodads）

| 功能 | 细节 |
|---|---|
| 放置 | 从调色板选模型，左键刷 |
| 随机化 | 随机旋转、随机缩放、随机变体 |
| 选中编辑 | XYZ 缩放、旋转、变体号 |
| 可见性标志 | 不可见非实体 / 可见非实体 / 可见实体 |
| 高度锁定 | 移动时保持绝对高度，不贴地 |
| 替换 | 选中的装饰物批量换成另一个模型 |

## 5. 单位

| 功能 | 细节 |
|---|---|
| 放置 | 选「作为哪个玩家」放置，自动带玩家色 |
| 选中 | 显示名字，可跳对象编辑器、可在调色板中定位 |
| 中键点选 | 直接点中脚下有单位的对象 |
| 编辑入口 | 属性在对象编辑器里改，调色板只负责摆放 |

## 6. 区域

矩形与圆形两种，属性有名字、颜色、天气效果、环境音，供触发器引用。

## 7. 相机

游戏相机（`war3map.w3c`）的放置与参数编辑：目标点、距离、水平角、垂直角、视野、远近裁剪。

## 8. 地图属性

| 页签 | 能改 |
|---|---|
| Description | 地图名、建议人数、描述、作者、地图版本、编辑器版本 |
| Options | 近战图、预览隐藏小地图、遮蔽区域半可见、悬崖边水波、缓坡水波、物品分类系统、地形雾 |
| Loading Screen | 加载画面（图片、标题、副标题、提示文本） |
| Map Size | 地图边界 |

场景信息编辑器（玩家 / 队伍）：

| 部分 | 状态 |
|---|---|
| Players（控制器、固定出生点、颜色、名字、种族） | 已实现 |
| Forces（队伍编组） | 界面在，功能未实现 |
| Techtree / Abilities / Upgrades | 界面在，功能未实现 |

## 9. 对象编辑器

七类对象的字段编辑：unit、item、doodad、destructible、ability、upgrade、buff。

| 功能 | 说明 |
|---|---|
| 浏览 | 每类一棵分类树 |
| 字段编辑 | 基于 SLK 元数据表（`UnitMetaData.slk` 等）自动生成表单 |
| 自定义对象 | 从原型派生，写到 `war3map.w3u` / `w3t` / `w3a` |
| 搜索定位 | 从单位调色板一键跳转 |

依赖整套 SLK / INI 合并，是 HiveWE 里第二重的模块。

## 10. 触发器编辑器

| 功能 | 说明 |
|---|---|
| 触发器树 | 分类 + 触发器的图形化结构 |
| 事件 / 条件 / 动作 | 参数由 `TriggerData.txt` / `TriggerStrings.txt` 驱动 |
| GUI ↔ 脚本 | 图形化编辑与 JASS 互转 |
| 脚本编辑 | 内置编辑器，语法高亮 |
| 编译检查 | 调外部 pjass 校验语法 |

## 11. 模型编辑器

打开 MDX，预览模型、骨骼、动画序列、材质层，面板调参数。

## 12. 资产管理器

浏览游戏数据（MPQ）与地图内嵌资源的目录树，预览纹理和模型，导出到磁盘。

## 13. 视图与操作

| 功能 | 说明 |
|---|---|
| 轨道相机 | 右键拖拽旋转、中键平移、滚轮缩放、一键重置 |
| 显示开关 | Units / Doodads / Pathing / Regions / Brush / Lighting / Water / Click Helpers / Wireframe / Debug / Minimap |
| 小地图 | 实时渲染，点击定位 |
| 全局搜索 | 双击 Shift 搜索所有对象 |
| 快捷键 | Ctrl+Z / Ctrl+Y 撤销重做，Space 切换选择模式，Ctrl+F 搜索 |

## 15. 不提供

- 游戏运行（交给 War3 本体）
- 地形高度图导出（只有导入）
- 战役（Campaign）编辑
- 多人协作、版本控制集成
- 自定义 UI 布局保存
